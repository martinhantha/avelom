# Glossar — Alpiplan / ogama

| Begriff | Bedeutung |
|--------|-----------|
| **Alpiplan** | Produkt- und Markenname (UI, Stores, Kommunikation gegenüber Kund:innen). |
| **ogama** | Interner Projekt-/Arbeitsname (Repository, technische Module, Lastenheft-Referenz). |
| **Tenant / Mandant** | Ein Unternehmen (z. B. eine Flugschule) mit strikt isolierten Daten. |
| **Schnelltermin** | Termin mit freiem Kontakttext ohne Pflicht-Kundendatensatz. |
| **Organisator-Assistent** | Dialogführung: Gegenfragen, Präferenzen, Kurzbefehle (kein Pflicht-Chat). |

Die Bezeichnungen **Alpiplan** und **ogama** sind bewusst getrennt: nach außen und im Branding gilt **Alpiplan**; in internen Spezifikationen darf **ogama** als Projektname genutzt werden.
